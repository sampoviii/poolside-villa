A full-stack web-based reservation and management system built with PHP and MySQL for Poolside Villa (Pansol, Calamba City, Laguna) as our Software Engineering 2 capstone project at City College of Calamba.

### Features
* Customer Portal: Account registration with email verification recovery, real-time availability calendar with 15-minute date locks, automated package/pax computation, GCash receipt upload, downloadable PDF receipts, and verified post-stay reviews.
* Caretaker and Staff Portal: Daily guest schedule dashboard, GCash payment proof verification, booking approval or rejection with custom messages, walk-in date blocking, and check-in balance recording.
* Admin and Owner Portal: Reservation monitoring dashboard with KPI cards and monthly trend graph, exportable CSV/PDF transaction reports, caretaker account management, dynamic GCash settings, and RA 10173-aligned audit logs.

### Tech Stack
* Frontend: HTML5, CSS3, JavaScript
* Backend: PHP
* Database: MySQL / phpMyAdmin
* Hosting: InfinityFree
